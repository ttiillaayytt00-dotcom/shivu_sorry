# Ek raat, ek khat

Apology site with the **same journey** as the original (date lock → letter → cute scenes → photos → forgive) but a **different look**:

- night sky + moon, not blush pink glass
- padlock + “chaabi”, not a pink heart form
- wax-seal envelope + typewriter letter
- orbs / sparks instead of cartoon bears
- film-reel photos instead of a pastel carousel
- “abhi nahi” dodges and shrinks; “haan, maaf” opens a quiet afterglow

Someone who already opened the pink site should not instantly think “same page.”

## Edit before you send

1. Open `js/config.js`
2. Set the secret date (`d`, `m`, `y`)
3. Change names if you want
4. Replace `assets/1.jpg` … `4.jpg` with real photos (same file names)

Default date is `02 / 08 / 2007` (from the original username). Change it if that is wrong.

## Open locally

Double-click `index.html` or:

```bash
cd dil-ki-baat
python3 -m http.server 8080
```

Then open http://localhost:8080

## GitHub Pages

Upload this folder as a repo and enable Pages on the root (or `/docs`).
